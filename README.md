# DeveloperStore Sales API

A prototype Sales API for the Ambev DeveloperStore developer evaluation, built on the .NET 8 template the challenge provides. It will record sales with complete CRUD, apply the quantity-based discount rules inside a DDD aggregate, require a JWT on every sales endpoint, and write the `SaleCreated`, `SaleModified`, `SaleCancelled` and `ItemCancelled` events to the application log. Work in progress.

The challenge statement is in [.doc/challenge.md](.doc/challenge.md).
